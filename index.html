The Problem
Three portals. Seven minutes. Every single loan.

Before ordering a verification, a processor has to figure out who actually holds the payroll data: The Work Number, Thomas & Company, or Truework. That means cross-referencing portals manually — 3 to 7 minutes per file, plus wasted order fees when you query the wrong platform.

How It Works
Three steps. No learning curve.
1

Highlight

Select any employer name in your LOS, web mail, or a PDF viewer.

2

Right-click

Choose "Lookup VOE Provider" from the context menu.

3

Act

A toast shows the provider, the employer code (one-click copy), and a deep link to the portal.

Features
Built for the processing desk
⚡

Zero-latency lookup

Local in-memory match against a bundled index. No network round-trip on lookup; results render in milliseconds.

📋

One-click code copy

Six-digit Work Number codes and Thomas & Company codes copy to the clipboard with one click — no re-typing.

🔌

Works offline

The full index lives in the extension. If the network is down, lookups keep working from the local cache.

🔁

Daily auto-sync

Once a day the extension silently reconciles against the open GitHub index. Failed syncs never interrupt work.

🛡️

Respects the page

Results render in an isolated Shadow DOM card — no LOS styling, no DOM scraping, no auto-flagging.

🆓

Free & open source

MIT-licensed. No account, no API key, no data leaves your browser.

Install
GitHub download (v1)

VOE Helper v1 is distributed directly from its GitHub repository — not the Chrome Web Store. Installation takes about a minute:

  1. Download: get the repository ZIP from github.com/Spuds0588/VOE-Helper and unzip it.
  2. Open the extensions page: visit chrome://extensions in Chrome.
  3. Enable Developer mode (toggle, top right).
  4. Load the extension: click "Load unpacked" and select the unzipped voe-helper folder. That's it — highlight an employer name, right-click, and look up.
