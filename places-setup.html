VOE Helper — setup

Set up your Google Places key

This key lets the side panel's Find address + phone button fill the employer address and phone (Form 1005 Item 1) from the employer's name. You pay Google directly from your own account — the key never leaves your browser.

  1. Step 1 · Create a Google Cloud project Use (or create) a project in the Google Cloud console. Any name works, e.g. “voe-helper”. Open the console
  2. Step 2 · Enable Places API (New) In the API Library search for “Places API (New)” (make sure it is the New one, not legacy) and click Enable. Open the API Library
  3. Step 3 · Attach billing to the project Places look-ups are billed pay-as-you-go against a billing account — required even while your free trial credit lasts. Open Billing
  4. Step 4 · Create the API key In Credentials, click Create credentials → API key, then click the key to restrict it: under API restrictions allow only Places API (New). That way the key can't be used for anything else. Open Credentials
  5. Step 5 · Paste it into VOE Helper Open the VOE Helper side panel → gear icon ⚙ (top right) → Employee auto-fill → paste the key into Google Places key. The panel stores it locally in your browser only — it is never sent anywhere except straight to Google when you run a look-up.
What it costs. Each look-up makes one Text Search request that pulls the employer's formatted address and phone number. Real-world bills run a fraction of a cent per employer you process; Google gives new accounts free trial credit, so a trial usually covers your first months of look-ups. If a look-up errors with a “Place Details / Text Search SKU… not enabled” message, go back to Step 2 — that is the API not switched on for the key.

Prefer not to use Google at all? The panel also always includes a free, keyless fallback (OpenStreetMap's Photon index) that fills the address without a key — no billing, no setup; it just can't guarantee phone numbers. Add a free Geoapify key (3,000 free look-ups/day) if you want phone numbers without Google.
