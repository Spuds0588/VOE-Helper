Manual VOE Search

No match in the local catalog? Work the provider search pages by hand: open → search → back → open → search → back, working down this list.

Found a match? Note the provider + employer code exactly as shown, then use Report this match below (or the full rule out-loud in the repo issue template). Only codes you can see yourself on the provider's own page count — the catalog stores nothing unverified.
Truework — quickstart ordering
Public ordering flow. When you arrive from this link the extension already types the employer name into the search box; you still pick the employer.
app.truework.com/requester/quickstart
The Work Number — employee portal
Public consumer front door (registration/login). Verifier ordering lives behind the logged-in VsPortal — no public prefill is possible on any TWN surface.
employees.theworknumber.com
Thomas & Company — tncverify portal
Employee login has a public Company Code field (the processor's EWV order form is client-side). Codes circulate on employer EWV flyers — see the catalog notes.
tncverify.com
Experian Employer Services
Public front door. Caution: codes that appear on employer pages are employee ACCESS codes, not verifier codes — never record one as a company code.
experian.com/employer-services
Vault Verify (Equifax, ex-2025)
Acquired by Equifax in Nov 2025; the front door now routes into The Work Number. Employer pages may still show a Company Code — check currentness before trusting one.
vaultverify.com
InVerify — legacy (DNS dead)
Decommissioning lane: CSUN moved off it in 2022, Equifax routes former users into PeopleHQ, and inverify.net no longer resolves (re-checked 2026-10-23). Kept for historical reference only — no link.
